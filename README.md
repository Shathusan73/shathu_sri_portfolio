# Srithusan — Software Engineer Portfolio

Premium personal portfolio built with Next.js, TypeScript, Tailwind CSS, Motion, and React Three Fiber.

## Scripts

```bash
pnpm dev
pnpm lint
pnpm typecheck
pnpm build
```

## Content

Edit copy, links, projects, skills, experience, and education in `src/data/`. Social links and email live in `src/data/site.ts` and `src/data/social.ts`.
